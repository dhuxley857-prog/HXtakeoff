# HX Test Project 001 — Architectural Specification

## K10/115 — W01 internal partition
70mm metal C-stud, 50mm acoustic mineral wool, one layer 15mm acoustic plasterboard each face, tape and joint finish. Nominal finished thickness 100mm.

## K10/125 — W02 acoustic partition
92mm metal stud, 75mm acoustic insulation, two layers 12.5mm acoustic plasterboard each face. Nominal finished thickness 142mm.

## K10/135 — W03 WC partition
70mm metal stud with moisture-resistant board to WC face and standard board opposite. Nominal finished thickness 100mm.

## M40/110 — F01 Kitchen/Dining floor
600 × 600mm porcelain floor tile, adhesive and grout to manufacturer requirements.

## M50/110 — F02 Living/Study floor
Engineered timber flooring with acoustic underlay.

## L20/410 — D01 doors
FD30 solid-core timber doorset where tagged D01.

## Benchmark
External test rectangle is dimensioned 9000mm × 5400mm. These dimensions are the independent calibration evidence for the test drawing. The benchmark footprint is 48.60m² before wall deductions.
